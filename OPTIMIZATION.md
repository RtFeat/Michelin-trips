# Оптимизация загрузки изображений

## Что было сделано

### 1. Lazy Loading компонент
Создан `src/components/lazy-image.tsx` с поддержкой:
- ✅ Intersection Observer для загрузки изображений при скролле
- ✅ Поддержка WebP с fallback на оригинальный формат
- ✅ Красивый shimmer-эффект во время загрузки
- ✅ Priority режим для критичных изображений

### 2. WebP генерация
- Скрипт `scripts/generate-webp.mjs` автоматически создает WebP версии
- WebP формат обычно на 25-35% меньше JPEG
- Поддержка браузерами: 95%+

### 3. Preload критичных ресурсов
В `src/routes/__root.tsx` добавлены preload hints для портретов путешественников

### 4. Оптимизация компонентов
- `src/components/image-gallery.tsx` - использует LazyImage
- `src/components/traveler-block.tsx` - использует LazyImage
- Priority загрузка для первого изображения в галерее

## Использование

### Установка зависимостей
```bash
npm install
```

### Генерация WebP версий
```bash
npm run optimize:images
```

Это автоматически создаст `.webp` версии всех изображений в `public/images/`.

### Build с оптимизацией
```bash
npm run build
```

Build автоматически запустит оптимизацию изображений.

## Результаты

### До оптимизации
- Все изображения загружаются сразу
- Только JPEG формат (136KB - 527KB на файл)
- Нет placeholder'ов
- ~5.5MB всего

### После оптимизации
- Изображения загружаются по мере прокрутки
- WebP формат с JPEG fallback (~25-35% меньше)
- Красивый shimmer-эффект при загрузке
- Preload критичных изображений
- ~3.5-4MB всего + ленивая загрузка
